# 🌍 Travel Magic – Smart Travel Guide

## Overview

Travel Magic is a simple and interactive travel guide web application developed using HTML, CSS, and JavaScript. The application helps users explore popular tourist destinations and view basic travel information through a user-friendly interface.

## Features

* Search destinations instantly
* Responsive and attractive user interface
* Dark Mode / Light Mode toggle
* Destination cards with travel information
* Easy navigation and user interaction

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages (Deployment)

## Destinations Included

* Chennai
* Ooty
* Goa
* Mysore
* Kodaikanal

## Project Structure

TravelMagic/

├── index.html

├── style.css

├── script.js

└── README.md

## How to Run

1. Download the project files.
2. Open `index.html` in a web browser.
3. Search for a destination using the search box.
4. Toggle Dark Mode if needed.
